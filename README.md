# Học Máy & Nhận Dạng

Tập hợp các mô hình phân loại cơ bản được cài đặt bằng Python thuần, phục vụ ôn tập môn Học Máy & Nhận Dạng.

## Các mô hình

| File | Thuật toán |
| :--- | :--- |
| [`src/id3.py`](src/id3.py) | Cây quyết định — Decision Tree (ID3) |
| [`src/map.py`](src/map.py) | Xác suất hậu nghiệm cực đại — Maximum A Posteriori (MAP) |
| [`src/mle.py`](src/mle.py) | Ước lượng hợp lý cực đại — Maximum Likelihood Estimation (MLE) |
| [`src/nbc.py`](src/nbc.py) | Phân lớp Naive Bayes — Naive Bayes Classifier (NBC) |

## Cài đặt & Chạy

```bash
pip install -r requirements.txt
python src/map.py
```
